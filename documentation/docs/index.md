# The rusEFI Manual

*From first spark to full tune*

The complete guide to running an engine on rusEFI: how electronic fuel injection works, installing
the software, flashing firmware, wiring, configuring, tuning and troubleshooting — on official rusEFI
hardware, with the rusEFI console and TunerStudio.

Every section carries a level badge:

| Badge | For |
|---|---|
| :material-circle:{ .level-basic } Basic | No prior EFI knowledge. Every term is explained the first time. |
| :material-circle:{ .level-intermediate } Intermediate | You have a running engine and know what VE, lambda and timing are. |
| :material-circle:{ .level-advanced } Advanced | Calibrators, firmware builders, unusual hardware. |

Examples and screenshots use the **Proteus F7** board. Where another official board differs, the
chapter says so.
